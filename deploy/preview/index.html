04 / THE AGENT ECOSYSTEM

Your coding environment.
A shared coordination layer.

Free-first today. An interchangeable runtime design for the harnesses your team chooses.

IMPLEMENTED RUNTIME

Groq

The operational custom Switch adapter. Separate role instructions, tools and context, with bounded budgets, concurrency controls and backoff for free-tier use.

IDE HOOK INTEGRATION

Antigravity

Development tool events meet ownership rules and the courtroom pipeline. Enable the supported workspace hook to connect your coding activity.

OPTIONAL EXTENSION TARGET

Claude Code

A place in the runtime architecture for teams choosing Anthropic's coding harness. Its adapter is future integration work, not a required subscription.

OPTIONAL EXTENSION TARGET

Codex

The same coordination vision for teams using OpenAI's coding agent. A configured, supported adapter is required before it can join this runtime.

OPTIONAL EXTENSION TARGET

OpenCode

An additional coding-harness target in the extensible configuration. Its native adapter is not bundled or reported online.
